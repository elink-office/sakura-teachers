簡単スライド

パワーポイントの代わりに、文字と写真をモニターへ

打った文字と写真が、そのまま大きく映ります。今日のめあて、問題文、注意のひとこと、作品の写真、発表する子の名前。 スライドを作り込まなくていいので、思いついたその場で出せます。写真の上に文字を重ねることもできます。 名簿は座席表・班分けと同じものが使えます。写真も文字も名簿も、外には送っていません。

大きく出す

全画面になります。→ か スペース で次へ、← で戻る、Esc で終わり。

使い方

パワーポイントの代わりに、文字と写真を大きくモニターに映すための道具です。登録もインストールもいりません。このページを開くだけで使えます。作ったものは残さないので、その場で打って、その場で出せます。

こんなときに

  • 今日のめあてを出しておく
  • 教科書のページ・問題文・キーワードを出す
  • 「となりの人と話してみよう」のような指示を出す
  • 参観日やグループ発表で、発表する子の名前と作品名を出す

文字を出す

  • 枠に打って「入れる」を押すと、1行が1枚になって下の一覧に並びます。何行でもまとめて入れられます（Ctrl＋Enter でも入ります）。
  • 改行したいところに / を入れると、そこで行が変わります。
    例：海の生きものを/しらべて分かったこと
  • // にすると、前のほうが小さい文字になります。見出しを付けたいときに使ってください。
    例：今日のめあて//分数のたし算ができる
  • 文字の大きさは、長さに合わせて自動で変わります。
  • 一覧の ▲▼ で出す順番を入れ替え、× で1枚だけ消せます。パソコンなら行をつかんでドラッグでも動かせます。

写真を出す

  • ⭐一覧の「＋」を押すと、その1枚に写真が入ります。すでに打った文字はそのままなので、打ち直す必要はありません。
  • 「写真をえらぶ」から、いくつでもまとめて入れられます。この場合はいちばん下に足されます。
  • 入れた写真は、写真をつかんでドラッグすると、別の行へ移せます（パソコンのみ）。写真の右上の×で、写真だけ外せます。
  • 一覧の文字の欄に打つと、写真の上に文字が重なります。文字の後ろには白い帯が付くので、写真の上でも読めます。
  • 写真は切れません。画面に収まるように、全部が入る大きさで出ます。
  • ⚠写真は保存されません。このページを閉じると消えるので、次のときは入れ直してください。もちろん、どこにも送っていません。

書体と、文字の位置

  • 書体はゴシック体・丸文字・明朝体から選べます（座席表と同じです）。
    丸文字はWindowsとiPad・Macだけです。入っていない機器では、静かにゴシック体になります。
  • 文字の位置は上・まん中・下から選べます。写真の上に文字を置くとき、写真の中身に重ならない位置にできます。

発表者を出す

  • 座席表や班分けで保存したクラスがあれば、選ぶだけで名前が入ります。班分けをしてあれば、班も一緒に入ります。
  • Excelから貼り付けることもできます。名前だけの1列でも大丈夫です。
  • 作品名を入れると、作品名が大きく、名前が下に出ます。名前は覚えているので、作品名を主役にしてあります。
  • 「班ごとにまとめて映す」を選ぶと、班名・その班の作品名・メンバー全員の名前が一緒に出ます。

順番を変えたい・今日いない子を外したい

  • 一覧の ▲▼ で順番を入れ替えられます。
  • チェックを外すと、その子（その班）は映りません。
  • 順番をシャッフルで、発表の順をランダムにします。班ごとに映すときは班の順が入れ替わり、班の中はそのままです。

子どもに設定を見せたくない

「先生の準備」を閉じると、中身がまとめて隠れます。「大きく出す」を押したときも自動で閉じますので、映し終わって戻ったときに、順番やシャッフルが子どもに見えることはありません。

打った文字は、どこにも送られません

打った文字と名簿は、この端末のブラウザの中だけに残ります。どこかのサーバーに送ることはありません。ネットにつながっていなくても動きます。映している画面には、広告は出ません。
